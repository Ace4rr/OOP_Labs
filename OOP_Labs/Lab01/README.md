# Лабораторная работа 1: Основы C++ — одна программа на динамических структурах данных

**Кафедра 806 МАИ, ООП (семестр 1)**  
**Семейство C:** Двумерные массивы, матрицы `int**`  
**Вариант 17:** Вычисление максимумов строк (`matrix_row_max`) и минимумов столбцов (`matrix_col_min`).

---

## Сборка и запуск

### 1. Сборка проекта (macOS / Linux)
```bash
cd Lab01
mkdir build && cd build
cmake ..
cmake --build .
```

### 2. Запуск программы с меню
```bash
./lab_01_exe
```

### 3. Запуск тестов Google Test
```bash
./lab_01_tests
# или через ctest:
ctest --output-on-failure
```

---

## Проверка на утечки памяти (AddressSanitizer)
Сборка автоматически компилируется с флагами `-fsanitize=address`. При выполнении программы и тестов проверяется корректное освобождение всех динамических массивов (`delete[]`).
