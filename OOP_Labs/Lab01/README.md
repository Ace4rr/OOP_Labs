## Сборка и запуск

### 1. Сборка проекта (macOS / Linux)
```bash
cd Lab01
mkdir -p build && cd build
cmake ..
cmake --build .
```

### 2. Запуск программы с меню
```bash
./lab01_main
```

### 3. Запуск тестов Google Test
```bash
./tests
```
